# 校园线上选餐

**郑大吃什么 · 校园选餐饭本（V5）**

一个面向校园日常选餐的静态 Web 产品。通过明确筛选、单次抽餐、独立餐品介绍和个人饭本，帮助用户从“想吃什么”走到“决定这一餐”。

**[公开体验网站](https://dd9uz8xl.qwenwork.host/)** · 无需登录。该地址由第三方免费托管，访问能力及额度以平台实际情况为准。

## 已实现的功能

- **选一餐**：早餐、午餐、晚餐切换，菜名搜索，分类、口味及收藏筛选；稳妥／尝新偏好；尽量避开最近三次推荐。明确筛选不会自动放宽，当前版本只保留单次抽餐。
- **逛菜单**：260条记录、252个不同菜名组、260张独立透明主图及对应缩略图；每道菜有专属介绍与搭配建议。每批展示24条，图片按需加载。
- **餐厅资料**：郑州大学主校区四个生活区、六家餐厅及荷园商业街的位置资料与来源。地点介绍与菜品供应相互独立。
- **个人饭本**：收藏、收藏夹、今日决定、周计划、用餐月历、评分及JSON备份。决定和计划不等于实际用餐，只有确认吃过才记入历史。
- **饮食参考**：可选身体资料与本地规则建议。部分菜品提供有来源的参考配方和估算热量，缺少可靠依据的保留未知；不提供诊断、医学忌口或每日热量处方。
- **交互与离线**：餐盘揭晓反馈、减少动画、键盘操作、哈希路由、有限离线访问；近期图片缓存最多30张。天气已取消，仅显示城市和日期。

## 本地启动

需要 **Node.js 22或更新版本**。运行代码和测试不依赖第三方npm包，无需执行npm install。

```bash
npm run preview
```

浏览器打开 `http://127.0.0.1:8765/`。用HTTP服务访问，不能直接双击HTML文件。也可设置环境变量 `PORT` 修改端口。

```bash
npm test
npm run build
npm run menu:workbench
```

测试覆盖推荐与筛选、个人数据迁移、导入拒绝、主餐资格、事实证据与营养参考、独立图片以及单抽界面。核实工作台位于本地生成的 `review/menu-workbench/`，不属于公开站点运行文件。

`npm run assets:check` 额外需要 Python 3与Pillow，用于图片透明度、边缘、大小和哈希检查；可通过 `CODEX_PYTHON_BIN` 指定Python解释器。

## 构建与部署

`dist/` 已包含可运行页面、ES模块、餐图和结构化源数据。构建会重新校验介绍、菜库、独立素材映射并更新离线资源版本。

生成精简静态部署目录（必须指定新的绝对路径，工具拒绝覆盖非空目录）：

```bash
node scripts/build-domestic.mjs --out /absolute/path/to/release
```

Windows可使用 `--out D:/output/campus-release`。将生成目录中的文件部署到支持HTTPS、正确JS/WebP MIME类型及Service Worker的静态托管服务。不要将整个源码仓库当作生产站点根目录，也不要上传个人饭本备份。

## 目录

| 路径 | 用途 |
|---|---|
| `dist/` | 页面、样式、ES模块、运行时菜库、图标和餐图 |
| `dist/data/menu.json` | 维护用完整菜库，包含稳定ID、编辑建议及事实核实状态 |
| `scripts/` | 构建、校验、预览、部署包生成及菜单维护工具 |
| `tests/` | 自动化测试与合成测试数据；不含真实用户饭本 |
| `tools/menu-workbench/` | 本地菜单维护界面源码 |
| `review/` | 必要的素材来源记录、哈希、历史身份基线和公开资料 |
| `deployment/domestic/` | 国内静态托管兼容脚本与样式 |

## 数据、营养与隐私

菜品是**选餐灵感，供应未核对**，并非实时食堂菜单。不保证实际商户、价格、配料、营业时间或在售情况。建议餐次、口味和介绍属于编辑参考，事实证据字段单独保留。

餐图为独立生成示意素材，不是窗口实拍；同一条目的缩略图由其主图派生，跨记录不复用。原200条记录的稳定ID和素材身份保持兼容。

260条记录中145条建立参考配方，130条具备完整营养来源可计算估算区间。食材依据来自USDA FoodData Central公开数据，来源位于 `review/nutrition-sources.json`。配方、份量和热量不是实测，不是完整配料表或过敏原保证。

饭本和可选身体资料只保存在各访客当前浏览器的本地存储中；无账号、无服务器健康档案。导出默认不包含身体资料；换域名需自行导出、预览并导入。分享链接不携带个人饭本。公开源码中的测试数据均为合成数据。

本公开副本基于V5整理，移除了开发者本机路径、托管项目配置、账号标识、历史Git记录、个人备份、浏览器数据和无关文件。提交使用通用作者信息，GitHub仓库所有者账号仍属于GitHub正常公开信息。原开发目录及已上线网站不受影响。
